## 1. 用例编写规则

| 项 | 说明 |
|---|---|
| 用例类型 | N = 正常流程；B = 边界条件；X = 异常场景 |
| 前置条件 | 执行前必须满足的账号、数据、状态 |
| 操作步骤 | 从入口到结果的完整操作链路 |
| 预期结果 | 页面提示、数据变化、状态流转或错误码 |
| 编号映射 | 自动化测试 docstring 标注 `TC-Vxx`，与本文一一对应 |

## 2. 急招专区

| 编号 | 类型 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| TC-V01 | N | 企业资质与 HR 已通过；存在 1 个 `APPROVED` 职位 | 企业进入职位管理 → 设置急招 7 天 → 学生进入急招专区 | 专区返回该职位；卡片显示「急招 · 剩 7 天」 |
