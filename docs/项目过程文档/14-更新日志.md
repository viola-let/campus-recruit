# 更新日志

> 维护方式：按版本倒序记录新增、变更、修复与升级说明

## v1.2.0（2026-11-20）

### 新增功能

| 模块 | 内容 |
|---|---|
| 急招专区 | 企业设置 1-30 天急招（占比 ≤ 30%），独立入口展示剩余天数，到期自动失效 |
| 企业文化交流区 | 在职 / 曾任职 / 实习过 / 未任职身份发言，匿名发布、先审后发、企业官方回应 |
| 企业评分 | 五维评分 + 50 字正文，简历核查门槛，样本 < 3 不展示，达标后进入推荐理由 |
| 小任务兼职 | 任务发布、审核、报名、名额与重复校验、关键词黑名单、防诈骗提示 |
| 招聘效果看板 | 浏览去重、投递 / 面试 / 录用漏斗、转化率、平均响应时长 |
| 候选人智能匹配 | 技能 / 专业 / 城市打分排序，展示匹配分与理由，可切换原始排序 |
| 企业主页 | 聚合官方品牌、在招职位、员工分享与员工评分 |
| 内容审核 | 文化帖、企业评分、小任务三合一审核队列 |

### 接口与数据

- REST 新增 `GET/POST /culture-posts`、`GET/POST /companies/{id}/reviews`、`GET /micro-tasks`、`POST /micro-tasks/{id}/signup`；
- `GET /jobs` 新增 `only_urgent` 参数；API 版本升级至 `1.2.0`；
- 新增数据表 `culture_posts`、`company_reviews`、`micro_tasks`、`task_signups`、`job_views`；
- `jobs` 表新增 `is_urgent`、`urgent_until`，老库由 `_migrate()` 自动补列；
- 新增错误码 `DUPLICATE_REVIEW`、`DUPLICATE_SIGNUP`、`DUPLICATE_CONTENT`、`TASK_FULL`（HTTP 409）。

### 体验与展示

- 每个新页面增加「功能说明与演示要点」折叠区，包含开发人员、功能背景、适用场景与演示要点；
- 新服务模块补充标准化展示注释；
- 新增 [v1.2 功能设计方案与实现说明](12-功能设计方案与实现说明.md)、[新增功能测试用例说明](13-新增功能测试用例说明.md) 与本更新日志。

### 部署与交付

- 新增 `deploy_app.py` 公网部署入口：首次启动自动建库，空库自动导入演示数据；
- 新增 `core/bootstrap.py`，保证免费托管环境临时磁盘重置后仍可一键演示；
- 新增 [公网免费部署指南](15-公网免费部署指南.md)，覆盖 GitHub 推送、Streamlit Community Cloud 部署、自检与排障。

### 测试

- 新增 12 条功能用例 + 13 条边界 / 异常用例，全量 **146 passed**；
- 覆盖正常流程、边界条件、异常场景三类；
- 四项质量门禁（ruff format / ruff check / compileall / pytest）全部通过。

### 升级说明

1. 拉取代码后执行 `python scripts/init_db.py`，自动创建新表并补齐字段；
2. 如需演示数据，执行 `python scripts/seed_test_data.py`（幂等）；
3. 已有职位默认非急招，需要在企业端职位管理中手动设置；
4. 文化帖、企业评分与小任务均需管理员在「内容审核」通过后展示。

## v1.1.0（2026-11-18）

### 新增功能

- 企业品牌：logo、简介、文化、行业、规模、融资、城市、福利；
- 多关键词 AND 搜索、仅标题搜索、岗位类别与三种排序；
- 智能推荐（技能 / 专业 / 城市 / 推荐位）与相似职位；
- 批量投递（≤ 20，逐条返回结果）与岗位收藏；
- 全平台主题、卡片、响应式与登录页演示账号提示。

### 接口与数据

- `companies` 新增 8 个品牌字段；新增 `favorites` 表；
- REST 新增详情、相似、推荐、收藏、批量投递、品牌与 logo 接口，版本升级至 `1.1.0`。

### 测试

- 新增 8 条用例，全量 121 passed。
