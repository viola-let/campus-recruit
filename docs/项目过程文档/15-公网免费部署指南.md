# 公网免费部署指南（初学者版）

> 项目：校招平台 CampusRecruit
> 文档版本：v1.2（2026-11-20）
> 适用人群：第一次部署 Web 项目的学生 / 课程项目负责人
> 目标：用 0 元成本得到一个可公开访问的演示地址
> 相关文档：[项目进入与访问指引](11-项目进入与访问指引.md) · [操作手册](07-操作手册.md)

---

## 1. 先给结论

**可行，而且不需要服务器、域名和信用卡。**

最适合本项目的免费方案是 **Streamlit Community Cloud**：

| 项 | 说明 |
|---|---|
| 费用 | 免费 |
| 需要准备 | 一个 GitHub 账号、一个公开仓库 |
| 部署对象 | 只用 Streamlit 页面（三端功能完整） |
| 访问地址 | `https://你的应用名.streamlit.app` |
| 适合场景 | 课程答辩、项目评审、简历作品展示 |

但必须提前知道三个限制：

| 限制 | 影响 | 应对 |
|---|---|---|
| 临时磁盘 | 应用重启 / 重新部署后，`data/app.db` 与上传文件会丢失 | 本项目已提供 `deploy_app.py`，空库时自动重建并导入演示数据 |
| 单进程 | Community Cloud 只运行一个 Streamlit 进程，FastAPI 的 `/docs` 不会公网可访问 | 页面功能不受影响；如必须展示 API，见第 8 节单独部署 |
| 休眠 | 一段时间无人访问会休眠，首位访问者需等待唤醒 | 答辩前 1 分钟先打开一次预热 |

## 2. 免费方案对比

| 平台 | 免费额度 | 优点 | 缺点 | 推荐度 |
|---|---|---|---|---|
| Streamlit Community Cloud | 免费、1 GB 内存 | 与项目技术栈完全匹配，部署最简单 | 临时磁盘、单进程、会休眠 | ★★★★★ |
| Hugging Face Spaces | 免费 CPU | 支持 Streamlit SDK / Docker | 同样临时磁盘，国内访问速度一般 | ★★★☆ |
| Render Free | 免费 Web Service | 可部署 FastAPI | 免费实例休眠、磁盘非持久、配置更复杂 | ★★★（仅 API） |
| PythonAnywhere | 免费账号 | 有免费空间 | 对 WebSocket / Streamlit 支持不好 | ★（不推荐） |

**结论**：页面演示选 Community Cloud；需要公网 Swagger 时再用 Render 单独部署 API。

| 检查项 | 要求 | 本项目状态 |
|---|---|---|
| GitHub 账号 | 已注册并完成邮箱验证 | 需你自行注册 |

## 4. 第一步：把代码推到 GitHub

### 4.1 在 GitHub 创建仓库

1. 登录 GitHub，点击右上角 `+` → `New repository`；
2. 仓库名例如 `campus-recruit`；
3. 选择 **Public**（Community Cloud 免费版需要公开仓库）；
4. 不要勾选初始化 README（本地已有）；
5. 点击 `Create repository`。

### 4.2 在本地初始化并推送

在项目根目录打开 PowerShell，依次执行：

```powershell
cd D:\AI_coding\project2

git init
git add .
git commit -m "feat: CampusRecruit v1.2"
git branch -M main
git remote add origin https://github.com/你的用户名/campus-recruit.git
git push -u origin main
```

首次推送会要求登录 GitHub。推荐使用 GitHub 的 Personal Access Token 作为密码，或安装 GitHub Desktop 图形化操作。

推送完成后，打开仓库页面确认：

- 能看到 `app.py`、`deploy_app.py`、`requirements.txt`；
- 看不到 `.venv/`、`data/app.db`、`uploads/` 中的真实文件、`.streamlit/secrets.toml`。

---

## 5. 第二步：在 Streamlit Community Cloud 部署

1. 打开 <https://share.streamlit.io>，用 GitHub 账号登录；
2. 点击 `Create app`（或 `New app`）；
3. 选择 `Deploy a public app from GitHub`；
4. 填写：
   - Repository：`你的用户名/campus-recruit`
   - Branch：`main`
   - Main file path：**`deploy_app.py`**（不要填 `app.py`）
5. 点击 `Advanced settings`：
   - Python version 选择 **3.12**；
   - Secrets 留空即可（本项目页面端不依赖密钥）；
6. 点击 `Deploy`，等待 2-5 分钟构建。

构建成功后，浏览器会打开：

```text
https://campus-recruit-xxxx.streamlit.app
```

首次打开时，`deploy_app.py` 会自动：

1. 创建 `data/app.db`；
2. 建表并执行老库迁移；
3. 空库时导入 20 家企业、50 份简历、30 个职位与社区演示数据；
4. 加载正常登录页。

## 7. 数据会丢吗？怎么处理

Community Cloud 的磁盘是临时的：

- **休眠唤醒**：通常数据还在；
- **重新部署 / 容器重建**：`data/app.db` 与 `uploads/` 会清空。

本项目已通过 `deploy_app.py` 处理：空库自动重新导入演示数据，所以演示始终可用，但**演示期间新产生的数据会丢失**。

如果必须持久化，需要额外接入免费的云数据库与对象存储（例如 Supabase 免费版），这需要改造 `core/db.py` 与上传逻辑，不适合第一次部署。课程演示阶段建议接受“每次重置为初始演示数据”。

## 8. 可选：把 REST API 也放到公网

页面端不需要 API 也能完整演示。若答辩要求展示 Swagger：

1. 在 Render 注册并新建 `Web Service`，连接同一个 GitHub 仓库；
2. Build Command：`pip install -r requirements.txt`；
3. Start Command：`uvicorn api.main:app --host 0.0.0.0 --port $PORT`；
4. 环境变量设置 `API_JWT_SECRET` 为随机长字符串；
5. 部署完成后访问 `https://你的服务.onrender.com/docs`。

注意：Render 免费实例也会休眠，且与 Streamlit 端不共享 SQLite 数据，仅适合接口演示，不适合真实业务。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 构建失败 `ModuleNotFoundError` | 依赖未写入 `requirements.txt` | 本地确认 `streamlit run app.py` 可启动后重新部署 |
| 构建失败提示 Python 版本 | 未选择 3.12 | 在 Advanced settings 重新选择 Python 3.12 |
| 打开报 `no such table` | 入口填成了 `app.py`，未执行建库 | 把 Main file path 改为 `deploy_app.py` 后重新部署 |
| 页面一直转圈 | 应用正在冷启动 | 等待 30-60 秒并刷新 |
| 登录后数据为空 | 首次种子导入失败 | 查看 Cloud 构建日志，或在本地确认 `scripts/seed_test_data.py` 可执行 |
| 上传 logo / 简历后重启丢失 | 临时磁盘限制 | 演示前重新上传，或接受演示数据重置 |
| 公网能打开但没有 `/docs` | Community Cloud 只跑 Streamlit | 按第 8 节单独部署 FastAPI |
| 想改代码后更新 | 未重新部署 | 推送 GitHub 后，在 Cloud 点击 `Reboot` 或重新部署 |

## 10. 安全与演示建议

1. **不要提交真实数据**：公开仓库只放代码与演示种子；
2. **修改默认管理员密码**：公网演示前可在种子脚本或管理端调整；
3. **不要放敏感信息**：`.streamlit/secrets.toml`、`.env` 已在 `.gitignore` 中；
4. **答辩前预热**：提前 1 分钟打开公网地址，避免首位访问等待；
5. **准备二维码**：拿到公网地址后，用任意免费二维码工具生成图片，放在 PPT 或简历中；
6. **准备降级方案**：若现场网络不稳定，保留本地 `streamlit run app.py` 作为备用演示。
