## 1. 评审范围与方法

### 1.1 评审范围

| 对象 | 版本 | 评审重点 |
|---|---|---|
| 前置任务清单 | v1.0 | 环境可行性、依赖约束、验证节点是否可执行 |
| 需求规格说明书 | v1.0 | 需求完整性、角色权限、验收标准可测试性 |
| 技术设计文档 | v1.0 | 架构一致性、数据模型、安全、可实现性 |

### 1.2 评审方法

1. **需求覆盖核对**：逐条对照图 1「案例 4：校招平台」的业务场景、三端功能与案例特点。
2. **一致性核对**：Spec 的规则是否在 TDD 中有对应设计；TDD 的表结构是否支撑 Spec 的验收标准。
3. **安全审查**：认证、授权、注入、上传、越权、敏感信息。
4. **可测试性审查**：每条验收标准能否转化为自动化测试。
5. **初学者可行性审查**：技术复杂度、依赖数量、抽象层级、单文件规模。
6. **官方一致性审查**：多页方案、配置、缓存、测试是否符合 Streamlit 官方文档。

### 1.3 评审输入的限制

- 当前处于阶段 4，尚未生成代码，评审基于文档而非运行结果。
- 未进行真实用户测试与压力测试。
- 外部依赖版本以 2026-11-18 官方文档为准。

## 4. 安全评审结论

| 检查项 | 结论 | 说明 |
|---|---|---|
| 认证 | 通过（MVP 级） | 邮箱 + 密码，PBKDF2 哈希；账号停用拦截 |
| 授权 | 通过 | 角色 + 资源归属双重校验，且落在服务层 |
| SQL 注入 | 通过 | 全部参数化查询，无字符串拼接 |
| 文件上传 | 通过（MVP 级） | 白名单、大小上限、UUID 命名、目录边界校验 |
| 敏感信息 | 通过 | 密钥与本地数据全部 gitignore；不在日志输出密码 |
| XSS | 通过 | 禁用 `unsafe_allow_html`；用户内容默认转义 |
| 会话安全 | 有条件通过 | 仅服务端 Session State，适合本地演示；公网需 OIDC |
| 登录限流 | 未实现 | 列为已知限制，公网部署前必须补充 |
| CSRF | 低风险 | Streamlit 的 WebSocket 会话模型降低风险，但公网仍需网关层防护 |

**结论：不存在未处理的 P0 安全问题。**

## 8. 已知限制与遗留风险

| 编号 | 限制 | 影响 | 接受理由 | 后续动作 |

| R-01 | SQLite 并发写能力有限 | 高并发时写锁等待 | 项目定位为本地演示，≤ 20 会话 | 需要时迁移 PostgreSQL |

## 11. 决策记录（v1.2）

### 11.1 已确认决策

| 编号 | 决策问题 | 结论 | 对文档的影响 |
|---|---|---|---|
| D-01 | REST/OpenAPI 做到哪一层 | **FastAPI 运行级 REST**：独立进程，自动输出 OpenAPI 3.1 | TDD 增加 `api/` 层与 6.5.7 端点清单；tasks 增加 M4.5；checklist 增加 C-110~C-115 |
| D-02 | 公网访问方式 | **Streamlit Community Cloud 演示** | 公网 URL / 二维码只指向 Streamlit |
| D-03 | 内部文档是否提交 | **不提交** | `docs/内部文档/` 不进入最终交付；仅保留在仓库 |

### 11.2 决策带来的约束（已在 TDD 与 Spec 写明）

| 约束 | 说明 |
|---|---|
| 单进程限制 | Community Cloud 只能运行一个 Streamlit 进程，无法同时启动 FastAPI |
| 公网 REST 不可用 | REST 与 `/docs` 只在本机或自建 VPS/Docker 可用；不作为公网能力承诺 |
| 业务唯一来源 | `views/` 与 `api/` 都只调用 `services/`，禁止复制业务规则 |
| 认证一致 | UI 用 Session State，REST 用 JWT Bearer；两者角色与归属判断一致 |
| 密钥管理 | `API_JWT_SECRET` 通过环境变量注入，不提交 Git |

### 11.3 明确不做

- 不使用 MCP stdio 替代 REST/OpenAPI。stdio 是本地进程间协议，只能被 MCP 客户端调用，无法被浏览器、Swagger、Postman 使用，也不能作为“API 设计”契约交付物。
- 不为了公网 REST 而引入 Docker / Nginx 反向代理（超出课程范围）。

### 11.4 决策后结论

D-01/D-02 存在天然冲突（单进程托管），已通过“REST 本地交付 + Streamlit 公网演示”的方式消解，并在 Spec 非目标、TDD 部署章节、checklist 验收项中三处留存记录。评审结论维持：**通过**。
