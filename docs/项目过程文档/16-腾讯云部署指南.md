# 腾讯云轻量服务器部署指南

> 项目：校招平台 CampusRecruit
> 文档版本：v1.2（2026-11-20）
> 适用场景：需要国内可访问、数据持久保存的公网演示
> 成本提示：使用腾讯云新用户试用 / 新人优惠，**试用到期后会转为付费**，请设置到期提醒。

---

## 1. 方案说明

| 项 | 内容 |
|---|---|
| 服务器 | 腾讯云轻量应用服务器（2 核 2G 起） |
| 系统 | Ubuntu 22.04 或 24.04 |
| 部署方式 | Docker 单容器运行 Streamlit |
| 访问方式 | `http://服务器公网IP:7860` |
| 数据 | SQLite 与上传文件挂载到 `/opt/campus-data`、`/opt/campus-uploads`，重建容器不丢 |
| 更新 | 重新执行一键脚本，自动拉取 GitHub 最新代码 |

---

## 2. 第一步：领取服务器

1. 打开 <https://cloud.tencent.com/>，注册并完成**实名认证**；
2. 进入「免费试用」或「轻量应用服务器」新人活动页；
3. 选择：
   - 地域：离你最近的地区（如广州、上海、北京）；
   - 镜像：**Ubuntu 22.04 LTS**；
   - 套餐：2 核 2G 起（内存低于 2G 构建镜像可能失败）；
4. 创建实例，记录**公网 IP**；
5. 在实例详情中重置 root / ubuntu 用户密码（或使用密钥）。

> 没有免费试用资格时，最低配轻量服务器通常也有新人价；请以控制台实际价格为准。

---

## 3. 第二步：放行端口

进入「轻量应用服务器 → 实例 → 防火墙」，添加规则：

| 协议 | 端口 | 用途 |
|---|---|---|
| TCP | 22 | SSH 登录 |
| TCP | 7860 | 平台公网访问 |

> 直接使用 `IP:7860` 访问通常不需要域名和 ICP 备案；若后续绑定域名并使用 80/443，需要按腾讯云要求备案。

---

## 4. 第三步：登录服务器

在实例页面点击「登录」，使用网页终端（OrcaTerm）即可，无需本地安装 SSH 工具。

---

## 5. 第四步：一键部署

在网页终端依次执行：

```bash
sudo apt-get update -y
sudo apt-get install -y git
sudo git clone https://github.com/viola-let/campus-recruit.git /opt/campus-recruit
sudo bash /opt/campus-recruit/scripts/tencent_deploy.sh
```

脚本会自动完成：

1. 安装 Docker；
2. 配置腾讯云内网镜像加速；
3. 拉取 GitHub 代码；
4. 构建镜像；
5. 启动容器并挂载持久化目录；
6. 输出访问地址。

看到类似输出即成功：

```text
部署成功：http://1.2.3.4:7860
```

浏览器打开该地址，用演示账号登录：

| 角色 | 账号 | 密码 |
|---|---|---|
| 学生 | `student01@seed.campus` | `Student123!` |
| 企业 | `company01@seed.campus` | `Company123!` |
| 管理员 | `admin@example.com` | `ChangeMe123` |

---

## 6. 更新代码

本地修改并推送到 GitHub 后，在服务器执行：

```bash
sudo bash /opt/campus-recruit/scripts/tencent_deploy.sh
```

脚本会拉取最新代码、重新构建并重启容器；`/opt/campus-data` 与 `/opt/campus-uploads` 中的数据保留。

常用运维命令：

```bash
docker ps                          # 查看容器
docker logs -f campus-recruit      # 查看日志
docker restart campus-recruit      # 重启
docker stop campus-recruit         # 停止
```

---

## 7. GitHub 拉取慢或失败时

腾讯云访问 GitHub 可能较慢。可在本地把仓库打包上传：

1. 在 GitHub 仓库页面点击 `Code → Download ZIP`；
2. 在网页终端点击上传文件，把 zip 上传到 `/tmp`；
3. 执行：

```bash
sudo apt-get install -y unzip
sudo rm -rf /opt/campus-recruit
sudo mkdir -p /opt/campus-recruit
sudo unzip /tmp/campus-recruit-main.zip -d /tmp/campus-src
sudo cp -r /tmp/campus-src/campus-recruit-main/. /opt/campus-recruit/
sudo bash /opt/campus-recruit/scripts/tencent_deploy.sh
```

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 浏览器打不开 `IP:7860` | 防火墙未放行 | 在腾讯云防火墙添加 TCP 7860 |
| 构建卡住或失败 | 服务器内存不足 / 镜像拉取慢 | 使用 2G 以上内存；确认已配置腾讯云 Docker 镜像 |
| `docker: command not found` | Docker 未安装成功 | 重新执行脚本，或 `apt-get install -y docker.io` |
| 容器启动后退出 | 依赖安装失败 | `docker logs campus-recruit` 查看第一条报错 |
| 页面能开但一直连接中 | WebSocket 被代理拦截 | 直接访问 7860，不要用不支持 WebSocket 的 CDN |
| 数据丢失 | 未使用持久化目录 | 确认启动命令包含 `-v /opt/campus-data:...` 与 `-v /opt/campus-uploads:...` |
| 试用到期实例被停 | 试用期结束 | 续费或释放实例；提前导出 `/opt/campus-data` |

---

## 9. 安全提醒

1. 公网演示前修改默认管理员密码，或不要公开管理员账号；
2. 防火墙只开放 22 与 7860，不要开放数据库端口；
3. 不要把 `.streamlit/secrets.toml`、真实简历、真实企业资料上传到服务器；
4. 试用到期前决定是否续费，避免自动扣费；
5. 长期使用建议绑定域名并配置 HTTPS（Nginx + 证书），Streamlit 需要额外转发 WebSocket 头。
