## 1. 运行前准备

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11、macOS 或 Linux |
| Python | 3.12.x（支持 3.11-3.15） |
| 浏览器 | Chrome / Edge 最新版 |
| 磁盘 | 至少 500 MB 可用空间 |
| 网络 | 仅安装依赖时需要；运行本身可离线 |

### 1.1 安装 Python

1. 打开 <https://www.python.org/downloads/>。
2. 下载 Python 3.12.x 64 位安装包。
3. 安装时勾选 **Add python.exe to PATH**。
4. 验证：

```powershell
python --version
```

预期输出 `Python 3.12.x`。

## 2. 首次安装

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```

若提示“禁止运行脚本”：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

验证 Streamlit：

```powershell
streamlit hello
```

浏览器出现示例应用即安装成功，按 `Ctrl+C` 停止。

## 3. 初始化数据库与演示数据

### 3.1 创建数据库与管理员

```powershell
python scripts/init_db.py --admin-email admin@example.com --admin-password "ChangeMe123"
```

执行后生成：

- `data/app.db`
- 6 张表：`users`、`companies`、`jobs`、`resumes`、`applications`、`review_logs`
- 1 个管理员账号

> 管理员密码只用于本地演示。真实部署请改用强密码，并通过环境变量或 `.streamlit/secrets.toml` 提供。

### 3.2 导入演示数据

```powershell
python scripts/seed_demo.py
```

生成：

| 角色 | 邮箱 | 密码 | 数据状态 |
|---|---|---|---|
| 管理员 | `admin@example.com` | `ChangeMe123` | 可审核 |
| 学生 | `student@example.com` | `Student123!` | 简历已核查 |
| 企业 | `company@example.com` | `Company123!` | 资质与 HR 已通过 |

### 3.3 导入模拟测试数据（演示与测试）

```powershell
python scripts/seed_test_data.py
```

生成 20 家公司、50 份简历、30 个岗位、96 条投递与对应审核日志，覆盖多行业、多规模、多城市、多层级与多岗位类型。演示账号：

| 角色 | 邮箱 | 密码 |
|---|---|---|
| 学生 | `student01@seed.campus` | `Student123!` |
| 企业 | `company01@seed.campus` | `Company123!` |

- 脚本幂等，可反复执行；只会清理 `@seed.campus` 域关联的模拟数据；
- 若真实学生已投递种子职位，脚本会中止，避免影响正式数据；
- 可用 `--db-path` 指向其他数据库文件。

### 3.4 重置数据

```powershell
Remove-Item data\app.db
Remove-Item uploads\resumes\* -Force
Remove-Item uploads\licenses\* -Force
python scripts/init_db.py --admin-email admin@example.com --admin-password "ChangeMe123"
python scripts/seed_demo.py
python scripts/seed_test_data.py
```

> 重置会删除全部本地数据与附件，仅建议在演示环境执行。

## 4. 启动与停止

### 4.1 启动

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`。

### 4.2 停止

在运行终端按 `Ctrl+C`。

### 4.3 更换端口

```powershell
streamlit run app.py --server.port 8502
```

### 4.4 启动 REST 接口（可选）

REST 与 Streamlit 是两个独立进程，共用同一份 `data/app.db`。需要查看或调用 OpenAPI 时，另开一个终端：

```powershell
.\.venv\Scripts\Activate.ps1
$env:API_JWT_SECRET = "本地开发用的随机长字符串"
uvicorn api.main:app --reload --port 8000
```

打开 `http://localhost:8000/docs` 即可在 Swagger 页面直接调试接口；接口契约文件为 `http://localhost:8000/openapi.json`（OpenAPI 3.1）。

**调用顺序：**

1. 先调用 `POST /api/v1/auth/login` 获取 `access_token`。
2. 点击 Swagger 右上角 **Authorize**，填入该 Token。
3. 再调用其他接口；未带 Token 返回 401，角色不符返回 403。

**注意：** REST 只在本地或自建服务器可用。Streamlit Community Cloud 只能运行一个 Streamlit 进程，公网地址不提供 REST 接口。

## 5. 学生端操作

### 5.1 注册与登录

1. 打开首页，选择“注册”。
2. 选择“学生”，填写邮箱、姓名、密码（≥ 8 位）。
3. 提交后返回登录页，使用新账号登录。

### 5.2 维护简历

1. 左侧导航进入“我的简历”。
2. 填写姓名、手机号、学校、专业、毕业年份、技能、简介。
3. 上传 PDF 或 DOCX 附件（≤ 5 MB）。
4. 点击保存，状态显示“待核查”。

> 简历修改后会自动回到“待核查”，需管理员重新核查后才能投递。

### 5.3 搜索职位

1. 进入“职位广场”。
2. 输入关键词（职位或企业），选择城市与类型（校招 / 实习）。
3. 点击查询，列表只展示已通过审核的职位。

### 5.4 投递与查看反馈

1. 在职位卡片点击“投递”。
2. 首次投递需确认简历状态为“已核查”。
3. 进入“我的投递”，查看状态：
   - 待查看
   - 已查看
   - 进入面试
   - 已录用
   - 不合适（附企业反馈）

## 6. 企业端操作

### 6.1 注册与资料提交

1. 注册时选择“企业”，填写企业名称、邮箱、密码。
2. 登录后进入“企业资料”，填写：
   - 企业名称
   - 统一社会信用代码
   - HR 姓名
   - HR 企业邮箱
3. 上传营业执照与 HR 在职证明（PDF / DOCX，≤ 5 MB）。
4. 提交后，资质与 HR 均显示“待审核”。

### 6.2 发布职位

1. 等待管理员分别通过“企业资质”和“企业 HR”。
2. 进入“职位管理”，点击“发布职位”。
3. 填写职位名称、类型、城市、薪资、描述（≥ 20 字）、要求。
4. 提交后职位状态为“待审核”，通过后学生可见。

### 6.3 管理候选人

1. 进入“候选人”。
2. 按职位、学校、专业、状态筛选。
3. 点击候选人查看投递时的简历快照与附件。
4. 更新状态：
   - 查看 → 已查看
   - 进入面试 → 需填写反馈
   - 录用
   - 不合适 → 反馈必填

> 已录用或已不合适的记录不可再次变更。

## 7. 管理端操作

### 7.1 概览

登录管理员账号后，首页展示：

- 待审企业资质
- 待审企业 HR
- 待审职位
- 待核查简历
- 投递总数
- 已录用数

点击指标可跳转到对应审核页。

### 7.2 企业审核

1. 进入“企业审核”。
2. “企业资质”页签：查看营业执照，选择通过或拒绝。
3. “企业 HR”页签：查看在职证明，独立审核。
4. 拒绝时必须填写理由；通过可不填。
5. 已处理记录不会再次出现在待审列表。

### 7.3 职位审核

1. 进入“职位审核”。
2. 查看职位详情与企业信息。
3. 通过后职位进入学生端；拒绝需填写理由。
4. 对已通过职位可开启“推荐”，学生列表优先展示。

### 7.4 简历核查

1. 进入“简历核查”。
2. 查看学生简历与附件。
3. 通过后学生可投递；拒绝需填写理由。

## 9. 常见问题（FAQ）

| 问题 | 原因 | 处理 |
|---|---|---|
| `python` 打开应用商店 | 使用的是 Windows 占位程序 | 安装 python.org 版本并勾选 Add to PATH |
| `python` 不是内部或外部命令 | 未加入 PATH | 重新安装并勾选 PATH，或手动添加 |
| 无法激活 `.venv` | PowerShell 执行策略限制 | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` |
| `ModuleNotFoundError: streamlit` | 未激活虚拟环境 | 先执行 `.\.venv\Scripts\Activate.ps1` |
| 端口 8501 被占用 | 已有 Streamlit 进程 | `streamlit run app.py --server.port 8502`，或结束旧进程 |
| 页面一直转圈 | 服务端异常 | 查看终端报错，按提示修复 |
| 上传失败 | 类型或大小不符合 | 仅 PDF/DOCX，≤ 5 MB |
| 无法投递 | 简历未核查 / 职位已关闭 / 已投递 | 查看页面提示 |
| 管理员登录失败 | 未初始化管理员 | 执行 `scripts/init_db.py` |
| 演示数据重复报错 | 重复执行 seed | 脚本应幂等；如失败先重置数据库 |

## 10. 数据备份与恢复

### 10.1 备份

```powershell
Copy-Item data\app.db backups\app-$(Get-Date -Format yyyyMMdd-HHmmss).db
Compress-Archive -Path uploads -DestinationPath backups\uploads-$(Get-Date -Format yyyyMMdd-HHmmss).zip
```

### 10.2 恢复

1. 停止应用（`Ctrl+C`）。
2. 将备份的 `.db` 放回 `data/app.db`。
3. 解压附件到 `uploads/`。
4. 重新启动。

> SQLite 文件必须在应用停止后复制，避免写入中断导致损坏。

## 12. 公网部署（可选）

### 12.1 Streamlit Community Cloud

1. 将代码推送到 GitHub 仓库。
2. 登录 <https://share.streamlit.io/>。
3. 选择仓库与分支，入口文件填 `app.py`。
4. Python 版本选择 3.12。
5. 在 Secrets 中配置必要密钥（本项目 MVP 可不配置）。
6. 部署完成后记录访问 URL。

### 12.2 二维码

使用任意二维码生成工具，将访问 URL 生成图片，保存为：

```text
docs/images/access-qr.png
```

并在 [项目介绍文档](../项目介绍文档.md) 与 README 中引用。

### 12.3 重要限制

Community Cloud 的本地文件系统不保证持久化：

- `data/app.db` 可能在重启后丢失；
- `uploads/` 中的附件可能丢失。

并且 Community Cloud **只运行一个 Streamlit 进程**，无法同时启动 FastAPI，因此公网 URL 只提供 Streamlit 页面，REST 接口与 `/docs` 不在公网可用。

因此公网版本只用于演示。长期使用需：

- 数据库替换为托管 PostgreSQL；
- 附件替换为对象存储（S3 / OSS）；
- 认证升级为官方 `st.login()` OIDC；
- 若需公网 REST，改为 VPS / Docker 部署两个进程。

## 14. v1.1 新增功能操作指引（2026-11-18）

### 14.1 学生：精准搜索与批量投递

1. 登录学生账号（如 `student01@seed.campus` / `Student123!`）。
2. 进入 **职位广场**：
   - 关键词支持多个词，用空格或逗号分隔，如 `Python 后端`；
   - 搜索范围可选「全部字段」或「仅职位名称」；
   - 可组合城市、类型（校招 / 实习）、岗位类别与排序。
3. 在目标职位卡片勾选 **加入批量**（已投递职位不可勾选）。
4. 点击 **批量投递已选**，页面提示成功 / 失败数量，失败原因会在提示中给出。
5. 投递成功后卡片显示「✓ 已投递」，可在 **我的投递** 查看进度。

### 14.2 学生：智能推荐与相似职位

1. 先完善简历（技能、专业、摘要中的期望城市会参与匹配）。
2. 进入 **智能推荐**，页面展示推荐画像与命中原因（技能匹配 / 专业相关 / 城市偏好 / 平台推荐）。
3. 在职位卡片点击 **查看详情**，详情页底部展示 **相似职位推荐**。
4. 点击卡片或列表中的 **☆ 收藏**，可在 **我的收藏** 集中查看。

### 14.3 企业：品牌信息维护

1. 企业账号登录，进入 **企业资料**。
2. 在「品牌展示」区域上传 logo（PNG / JPG / JPEG / WEBP，≤ 2 MB）。
3. 填写企业简介、企业文化、所属行业、企业规模、融资阶段、所在城市与福利标签，点击 **保存品牌信息**。
4. 页面底部「品牌展示预览」即为学生视角效果；品牌维护不会重置资质或 HR 审核状态。
5. 发布职位时选择 **岗位类别**，系统会自动写入标题前缀 `【类别】`，便于学生筛选。

### 14.4 管理端

管理流程与 v1.0 一致；新增的品牌信息无需审核，职位审核通过后品牌内容随职位一起展示。

## 15. v1.2 新增功能操作指引（2026-11-20）

### 15.1 学生：急招专区

1. 登录学生账号，左侧「求职中心 → 急招专区」。
2. 页面只展示仍在有效期内的急招职位，卡片标签显示「急招 · 剩 N 天」。
3. 投递方式与职位广场一致；急招到期后自动回到普通职位列表。

### 15.2 学生：企业文化交流区

1. 进入「校园社区 → 企业文化」。
2. **浏览企业口碑**：选择企业，查看综合口碑、推荐率与员工分享；点击「查看企业主页」可看品牌与在招职位。
3. **发布经验 / 提问**：
   - 选择任职状态（在职 / 曾任职 / 实习过 / 未任职）；
   - 未任职只能选择「求职提问」；
   - 经验帖正文至少 30 字，提问至少 10 字；
   - 可勾选匿名，前台显示「匿名用户」；
   - 提交后进入审核，通过后在「我的发布」中状态变为已通过。
4. 同一企业对同一学生 7 天内只能发 1 条经验帖，全站每天最多 3 条。

### 15.3 学生：企业评分

1. 进入「校园社区 → 企业评分」。
2. 前提：简历已核查，且身份为在职 / 曾任职 / 实习过。
3. 选择企业，填写成长、薪酬、强度、面试、推荐意愿五个维度（1-5 分）与不少于 50 字的正文。
4. 提交后进入审核；同一企业同一任职身份只能评分一次。
5. 企业评分样本少于 3 条时，前台只提示「样本不足」，不展示分数。

### 15.4 学生：小任务兼职

1. 进入「校园社区 → 小任务」。
2. 浏览招募中任务，点击「立即报名」；名额已满或已报名时按钮不可用。
3. 页面顶部固定展示防诈骗提示：平台不参与资金结算，要求交押金 / 垫付 / 刷单的均为诈骗。
4. 报名记录在页面底部「我的报名」查看。

### 15.5 企业：急招与招聘看板

1. 进入「职位管理」，对已通过职位设置急招天数（1-30 天），或取消急招。
2. 急招岗位不得超过本企业在招岗位的 30%，超出时页面提示。
3. 进入「招聘看板」查看浏览、投递、面试、录用、投递转化率与平均响应时长。
4. 浏览数为去重后的学生人数，同一学生重复打开详情只计一次。

### 15.6 企业：企业社区与小任务

1. 进入「企业社区 → 员工分享与回应」，对已通过帖子填写官方回应（5-500 字，仅一次）。
2. 在「收到的评分」查看本企业综合口碑与待审 / 已通过评价。
3. 进入「小任务」发布任务，填写名称、说明（≥ 30 字）、城市、报酬、时间与人数。
4. 任务提交后进入审核；审核通过后学生可见，企业可在任务卡片中查看报名名单或结束任务。

### 15.7 企业：候选人匹配排序

1. 进入「候选人」，保持「按岗位匹配度排序」勾选。
2. 候选人卡片展示匹配分与命中理由（技能匹配 / 专业相关 / 城市匹配）。
3. 取消勾选可恢复按投递时间排序；匹配分仅作参考，不改变投递状态。

### 15.8 管理员：内容审核

1. 进入「内容审核」，三个页签分别为文化帖、企业评分、小任务。
2. 查看内容与身份标签，点击「通过」或「拒绝」。
3. 已处理内容不会再次出现在待审列表；管理员首页新增三项待审计数。

### 15.9 新增模块 FAQ

| 问题 | 原因 | 处理 |
|---|---|---|
| 新页面报 `no such table` | 旧数据库未迁移 | 执行 `scripts/init_db.py`，`_migrate()` 会自动补列建表 |
| 急招设置失败 | 超过 30% 比例或职位未通过审核 | 先减少急招数量或等职位审核通过 |
| 发布经验提示只能提问 | 任职状态选择了「未任职」 | 选择在职 / 曾任职 / 实习过，或改为提问 |
| 评分按钮提交后无展示 | 评分需管理员审核 | 进入管理端「内容审核 → 企业评分」通过 |
| 企业评分不显示数字 | 样本少于 3 条 | 等待更多已通过评价 |
| 无法发布小任务 | 资质或 HR 未双审 | 先完成企业资质与 HR 审核 |
| 小任务发布被拒绝 | 命中刷单 / 押金等黑名单 | 调整内容，平台禁止资金类任务 |
