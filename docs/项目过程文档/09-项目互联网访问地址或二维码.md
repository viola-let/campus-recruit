## 4. 部署方式（暂定）

1. 将代码推送到远程仓库。
2. 登录 <https://share.streamlit.io/>。
3. 选择仓库与分支，入口文件填 `app.py`。
4. Python 版本选择 3.12。
5. 部署完成后记录访问 URL。
6. 用 URL 生成二维码，保存为 `docs/images/access-qr.png`。

## 5. 重要限制

Streamlit Community Cloud 的本地文件系统不保证持久化：

- `data/app.db` 可能在重启后丢失；
- `uploads/` 中的附件可能丢失。

因此公网版本仅用于演示。若要长期在线，需要替换为：

- 托管 PostgreSQL；
- 对象存储（S3 / OSS）；
- 官方 `st.login()` OIDC 认证。

**另一条限制：** Community Cloud 只运行一个 Streamlit 进程，无法同时运行 FastAPI。因此公网只提供 Streamlit 页面，**REST 接口与 OpenAPI 文档不在公网可用**；若需要公网 REST，必须改用 VPS / Docker 分别运行两个进程。
