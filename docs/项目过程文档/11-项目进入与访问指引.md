# 项目进入与访问指引

> 项目：校招平台 CampusRecruit
> 文档版本：v1.2（2026-11-20）
> 适用代码版本：v1.2.0
> 读者：开发、测试、演示与运维人员

本文档说明如何从零进入本项目：本地开发环境启动、访问地址、演示账号、部署环境入口、数据重置与常见问题。所有命令均以 **项目根目录** 为工作目录，Windows PowerShell 示例，macOS / Linux 将 `.\.venv\Scripts\` 替换为 `.venv/bin/` 即可。

---

## 1. 访问入口速查

| 入口 | 地址 | 说明 |
|---|---|---|
| Web 主站（Streamlit） | <http://localhost:8501> | 学生端 / 企业端 / 管理端统一入口 |
| REST API | <http://localhost:8000/api/v1> | JWT Bearer 认证 |
| Swagger 交互文档 | <http://localhost:8000/docs> | 在线调试全部接口 |
| OpenAPI 契约 | <http://localhost:8000/openapi.json> | 与 `api/openapi.json` 保持一致 |
| 健康检查 | <http://localhost:8000/health> | 返回 `{"status":"ok"}` |
| 部署环境 | 由部署平台分配的 HTTPS 域名 | 见第 6 节 |

- Streamlit 与 FastAPI 是**两个独立进程**，共用同一份 `data/app.db`，可以只启动其中一个。
- 默认端口可通过 `--server.port` / `--port` 修改，修改后对应地址同步变化。

## 3. 本地开发环境启动

### 3.1 环境要求

| 项 | 要求 |
|---|---|
| Python | 3.12.x（支持 3.11-3.15） |
| 浏览器 | Chrome / Edge 最新版 |
| 磁盘 | 至少 500 MB |
| 网络 | 仅安装依赖时需要 |

### 3.2 安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```

若提示禁止运行脚本：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 3.3 初始化数据库与演示数据

```powershell
python scripts/init_db.py --admin-email admin@example.com --admin-password "ChangeMe123"
python scripts/seed_demo.py
python scripts/seed_test_data.py
```

- `init_db.py`：建表、建索引、补充老库缺失字段，并创建管理员。
- `seed_demo.py`：创建演示学生 / 企业账号与 2 个演示岗位。
- `seed_test_data.py`：导入 20 家企业、50 份简历、30 个岗位、96 条投递与收藏数据，可重复执行。

### 3.4 启动 Web 主站

```powershell
streamlit run app.py
```

看到 `You can now view your Streamlit app` 后，浏览器打开 <http://localhost:8501>。

首次启动会在项目根目录生成 `data/app.db` 与 `uploads/`；两者均已加入 `.gitignore`，不会进入版本库。

### 3.5 启动 REST API（可选）

另开一个终端：

```powershell
.\.venv\Scripts\Activate.ps1
$env:API_JWT_SECRET = "本地开发用的随机长字符串"
uvicorn api.main:app --reload --port 8000
```

| 地址 | 用途 |
|---|---|
| <http://localhost:8000/docs> | Swagger UI，可先调用 `/api/v1/auth/login` 获取 Token |
| <http://localhost:8000/openapi.json> | OpenAPI 3.1 契约 |

获取 Token 后，在 Swagger 右上角 **Authorize** 填入 `Bearer <token>` 即可调试受保护接口。

### 3.6 运行质量门禁

```powershell
.\.venv\Scripts\python.exe -m ruff format --check .
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m compileall -q core services api views scripts app.py
.\.venv\Scripts\python.exe -m pytest
```

当前基线：**146 个自动化测试全部通过**。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `CAMPUS_DB_PATH` | `data/app.db` | 数据库文件路径；测试通过该变量使用临时库 |

```powershell
$env:CAMPUS_DB_PATH = "data/demo.db"
$env:API_JWT_SECRET = "请替换为至少 32 位随机字符串"
```

## 5. 演示路径建议

1. **学生端**：`student01@seed.campus` 登录 → 职位广场（多关键词 + 类别 + 城市筛选）→ 勾选 2-3 个职位批量投递 → 智能推荐 → 我的收藏 → 我的投递。
2. **急招与社区**：急招专区查看剩余天数 → 企业文化浏览 / 发布经验 → 企业评分 → 小任务报名。
3. **企业端**：`company01@seed.campus` 登录 → 企业资料（上传 logo、维护简介 / 文化 / 福利）→ 职位管理（发布岗位、设置急招）→ 候选人（匹配排序）→ 招聘看板 → 企业社区（官方回应）→ 小任务。
4. **管理端**：`admin@example.com` 登录 → 内容审核（文化帖 / 评分 / 小任务）→ 企业审核 / 职位审核 / 简历核查 → 概览指标。
5. **REST**：`/docs` 调用 `GET /api/v1/jobs?keyword=Python&category=技术&only_urgent=true`，或 `POST /api/v1/jobs/batch-applications` 演示批量投递。

## 6. 部署环境访问入口

### 6.1 Streamlit Community Cloud（最简）

1. 将代码推送到 GitHub 仓库（确认 `data/`、`uploads/` 未提交）。
2. 登录 <https://share.streamlit.io> → **New app** → 选择仓库与 `app.py`。
3. 在 **Advanced settings → Secrets** 写入（TOML）：

```toml
API_JWT_SECRET = "生产环境随机长字符串"
```

4. 部署完成后访问 `https://<应用名>.streamlit.app`。

> 注意：Community Cloud 只运行 Streamlit 进程，不提供 FastAPI；重启后 `data/` 与 `uploads/` 可能被重置，建议在启动脚本中执行 `init_db.py` 与 `seed_demo.py`，或挂载外部数据库/对象存储。

### 6.2 自有服务器（Web + API 同时对外）

```bash
# Linux 示例
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Web
nohup streamlit run app.py --server.port 8501 --server.address 127.0.0.1 &

# API
export API_JWT_SECRET="生产环境随机长字符串"
nohup uvicorn api.main:app --host 127.0.0.1 --port 8000 &
```

使用 Nginx 反向代理并配置 HTTPS：

```nginx
server {
    listen 443 ssl;
    server_name recruit.example.com;

    location / {
        proxy_pass http://127.0.0.1:8501;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
    }

    location /docs { proxy_pass http://127.0.0.1:8000; }
    location /openapi.json { proxy_pass http://127.0.0.1:8000; }
}
```

| 部署后入口 | 示例 |
|---|---|
| Web 主站 | `https://recruit.example.com` |
| REST API | `https://recruit.example.com/api/v1` |
| Swagger | `https://recruit.example.com/docs` |
| 健康检查 | `https://recruit.example.com/health` |

- [ ] 已更换管理员与演示账号密码
- [ ] 已设置 `API_JWT_SECRET`，未使用默认值

## 7. 数据重置与隔离

```powershell
# 重置种子数据（只清理 @seed.campus 账号及其关联数据）
python scripts/seed_test_data.py

# 写入独立数据库，完全不影响正式库
python scripts/seed_test_data.py --db-path data/demo_seed.db
```

- 脚本幂等，可反复执行，数量与内容稳定。
- 检测到真实学生投递种子职位时会中止，避免误删正式数据。
- 自动化测试使用 `tmp_path` 临时数据库，不会触碰 `data/app.db`。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `python` 提示“找不到命令”或跳转微软商店 | 未安装 Python 或 PATH 未生效 | 重新安装并勾选 **Add python.exe to PATH**；或使用 `py` 启动器 |
| `streamlit` 命令不存在 | 虚拟环境未激活 | 执行 `.\.venv\Scripts\Activate.ps1`，或使用 `python -m streamlit run app.py` |
| 端口 8501 被占用 | 已有实例在运行 | `streamlit run app.py --server.port 8502` |
| 页面显示“请先登录” | 会话未建立 | 从登录页进入，或清除浏览器缓存后重试 |
| 职位广场为空 | 岗位未审核通过或已关闭 | 用管理员账号审核岗位，或检查种子数据是否导入 |
| 投递按钮置灰 | 简历未通过核查 | 用管理员账号核查简历后再投递 |
| 批量投递提示部分失败 | 重复投递或职位已关闭 | 查看失败原因提示，已成功的投递不会回滚 |
| API 返回 401 | Token 缺失或过期（8 小时） | 重新调用 `/api/v1/auth/login` 获取 Token |
| logo 无法上传 | 文件类型或大小不合规 | 仅支持 PNG / JPG / JPEG / WEBP，≤ 2 MB |
| 种子脚本报“检测到非种子学生投递” | 真实账号投递过种子职位 | 使用 `--db-path` 写入独立库，或先清理该投递 |
| 新页面报 `no such table: culture_posts` | 旧数据库未执行建表 / 迁移 | 执行 `python scripts/init_db.py`，再重新启动 |
| 急招设置被拒绝 | 超过在招岗位 30% 或职位未通过审核 | 减少急招数量或先完成职位审核 |
| 评分提交后看不到 | 内容需管理员审核 | 管理端「内容审核 → 企业评分」通过 |
| 企业评分不显示分数 | 已通过样本少于 3 条 | 等待更多评价通过审核 |
